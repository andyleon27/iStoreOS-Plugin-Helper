## 2. 新增 / 修改的 UI 控件

新增一个轻量原生控件文件 `Controls\RoundedControls.cs`：

- `RoundedDrawing`：共用圆角路径、Region 更新 / 释放。
- `RoundedPanel`：白卡片和高级分组。
- `RoundedButton`：主操作、连接、选择文件和高级操作按钮。
- `RoundedIconButton`：密码眼睛按钮。
- `RoundedTextBox`：三项输入的圆角外层，保留原生编辑控件。
- `RoundedDropZone`：圆角虚线拖拽区与 hover / drag 反馈。
- `DropCaption`：两行字号 / 颜色层级。
- `StatusDot`：真正绘制的圆形状态点，连接状态不再使用 `●` 字符。

“高级信息 ›”改为 `LinkLabel`，hover 下划线，仍打开同一个非模态 AdvancedInfoForm。高级窗口仍为 800×600，只统一背景、操作按钮和 10px 圆角分组，原五页、日志、保存、源检测及 Package Diff 功能保持。

## 3. RoundedPanel 实现方式

使用 `GraphicsPath.AddArc` 生成闭合路径，`SmoothingMode.AntiAlias`，白色填充和浅色 1px 边框。开启 `UserPaint`、`AllPaintingInWmPaint`、`OptimizedDoubleBuffer`、`ResizeRedraw`，并设置 `DoubleBuffered=true`。

尺寸变化时重新生成 Region，替换后释放旧 Region；释放控件时也释放最后一个 Region。绘制中的 Path、Pen、Brush 均使用 `using`。不实现阴影或外窗皮肤。

## 4. RoundedTextBox 实现方式

`UserControl` 外层绘制圆角白底和边框，内部继续使用 **Borderless 原生 TextBox**。主窗口原 `hostBox`、`usernameBox`、`passwordBox` 仍指向该原生编辑器，所以原读取、Clear、MaxLength、PasswordChar、SelectionStart、焦点和连接逻辑无需改写。

外层 `Text` 双向代理，原生 `TextChanged` 向外层发送一次事件；保留 / 转发 KeyDown，支持 PasswordChar 与 UseSystemPasswordChar。普通边框 1px，Focus 边框 1.75px，左侧内距 10px。

缩放时外层负责编辑器定位，禁止内层再次自动缩放几何，避免重复放大。字体变化和 Layout / Resize 都重新计算原生编辑器的 PreferredHeight 与垂直居中。原密码眼睛调用和连接后清空 / 隐藏行为不变。

## 5. RoundedButton 实现方式

继承 **Button**，保留 Click、PerformClick、AcceptButton、键盘 / 验证及 Enabled 语义，只通过 OnPaint 替换外观。统一绘制圆角填充、次要边框、居中的文字 / 可选图标、键盘焦点提示，以及 normal / hover / pressed / disabled 状态。

文字测量使用无宽度约束的测量矩形，再在实际按钮宽度内绘制；修正了初版自绘时短文字被过早省略的问题。图标使用现有资源、双倍采样位图和高质量缩放，缺失时继续显示文字。没有新增业务事件。

## 6. RoundedDropZone 实现方式

继承 RoundedPanel，共用同一圆角算法；边框使用 `Pen.DashStyle=Dash`、抗锯齿和 12px 圆角。Hover / 接受拖入时改变浅蓝填充和边框，DragLeave / Drop 恢复。

外层、标题区域和上传图标继续调用原 `DropLabel_DragEnter` / `DropLabel_DragDrop`，沿用“单个 `.run`、安装忙时拒绝”的规则；文件选择仍调用原 `SelectPlugin` / ChooseButton 处理器。视觉反馈不决定兼容性或安装结果。
