## 2. 运行入口与调用约定

服务入口：

~~~csharp
Task<MaintenanceMenuRunResult> RunMaintenanceMenuAsync(
    RouterEnvironment expected,
    Action<MaintenanceMenuTerminal> terminalReady,
    IProgress<MaintenanceOperationLog> progress,
    CancellationToken token,
    string commit = null, uint columns = 100, uint rows = 30);
~~~

不传 commit 时，main 只解析一次，随后 menu.sh 与 LICENSE 均按同一个完整 SHA 下载；显式 commit 必须是合法完整 SHA。终端初始行列范围为 1–1000。缺少绑定回调、非法 SHA 或非法尺寸在任务副作用前拒绝。

terminalReady 在工作线程上调用，且发生在读取输出和发送启动命令前。界面应同步切换到 UI 线程完成 `terminalView.Bind(terminal)` 后返回；不能把绑定延迟到无等待的 BeginInvoke 后就返回。关闭终端由所属窗口调用 `await terminal.CloseAsync()`，窗口释放时应解除绑定或释放 TerminalView。不要调用首页 ssh.Dispose() 来关闭终端。

TerminalView 通过相同 IInteractiveTerminalSession 合约发送原始键盘、回车、Ctrl+C 和粘贴输入，并接收 Output；控制器在启动命令已入队前拒绝用户输入。CloseAsync 幂等，后台关闭通道并等待会话结束，不在 UI 线程执行同步 SSH I/O。

## 3. 连接、目录与资源生命周期

1. SshService 在同一个 sync 锁内检查 disposed、connecting、softwareBusy 和未完成安装。要求首页已连接、认证工厂可用，且 expected 的指纹与该主机/端口已信任的 Host Key 相符。不需要旧七插件 Phase 1 在线扫描批准；固定来源下载仍是在线门槛。
2. 设置 softwareBusy，建立链接调用方 token 的任务生命周期。首页重连、安装、软件检测、软件源操作、原插件维护及第二个菜单任务均被现有忙状态拒绝。
3. 复用 PluginMaintenanceExecutionService 的准备代码和互斥：下载并校验固定 SHA 菜单与 LICENSE，创建新的本地/远端归属目录，生成本次 runId 的独立 launcher。
4. 使用原 CreateTrustedTransfer 和 SFTP 上传 menu.sh、LICENSE、NOTICE.txt、helper-launcher.sh；四个文件均做本地 SHA256 和绑定完整远端路径的 SHA256 比对。原菜单与 LICENSE 字节不改变。
5. 四文件验证通过后，在原 SshClient 上创建独立 ShellStream，申请 xterm-256color PTY、初始行列、8192 字节缓冲；不创建新的 SSH 认证，不更换首页连接，不使用非 PTY 回退执行。
6. 绑定输出消费者，启动唯一读写会话，首先发送阶段 3 的单行短命令。协议先观察原始 Output，再转发给视图；关闭视图的输出消费者异常不会中断协议或清理。
7. 正常 EOF 时读写任务全部结束后才确认通道结束；手动 Close 或取消会带取消原因完成协议。网络错误在已缓冲输出读完后传播。EOF 本身不能判定成功。
8. 同一已认证 SSH 连接上另开有界 exec 命令，复用原 CommandAsync 查询任务状态。原始流缺标记时，仅有效持久 EXITED 证据可以恢复结果；冲突、运行中或不可确认均保留 Unknown 和远端任务目录。
9. 仅在阶段 3 的 CanCleanup 成立时执行完成清理，核对 CLEANED 回复。已尝试发送启动命令后绝不退回准备预览清理。清理使用独立的 20 秒 token，即使用户 token 已取消也能受控复核。
10. 清理本地四文件任务目录，生成状态/清理警告，最后释放维护互斥和 softwareBusy。互斥覆盖运行、最终输出排空及清理全过程。

`RunMenuAsync` 使用同一活跃任务目录，解决阶段 2 预览返回前已清理的问题。原 `PrepareMenuAsync` 的预览生命周期保持不变，不能把它的结果路径交给运行入口。

启动可能发送但尚无 START 证据时也记为 ExecutionAttempted。仅关闭终端通道不终止首页 SSH；关闭整个 SshService 则取消准备/终端，再按原行为关闭首页连接。没有自动重连或重复启动。

## 4. 结果与清理

返回值 Preparation 保留来源 SHA、载荷 hash、目录、执行尝试标志、Completed/ScriptFailed/FinalStateUnknown 和清理警告；Runtime 返回 PID、startTicks、Unix 启动时间、退出码及 CleanupCompleted。

- 菜单退出码 0：Completed / ExitedNormally。
- 菜单已知非零退出：ScriptFailed / ExitedWithError，可在状态复核后清理。
- EOF 缺证据、写入失败、断线或冲突：FinalStateUnknown / Unknown，不走普通准备清理。
- 已知退出但清理失败：保留已知退出结果，同时 RemoteCleanupSucceeded=false 和明确 CleanupWarning；不把清理失败误当脚本运行失败。
- 准备取消或 PTY 创建/绑定失败且未尝试启动：通过原有归属和白名单检查清理准备载荷。

## 6. 风险与下一步边界

1. 测试没有真实 SSH 服务端握手、SFTP 上传或路由器 BusyBox/PTY 验证。真实设备的 PTY 支持、网络中断时序和 Ctrl+C 进程组行为仍需后续联调。
2. 菜单通道和首页共享一个 SSH 连接。关闭菜单不会断开首页；底层网络或服务器断开会影响同一连接上的所有通道。不会自动重连后重发菜单。
3. 关闭菜单窗口只关闭通道，不能保证远端安装动作已经停止。无法确认的任务会保留远端目录及 Unknown，需要后续界面呈现和恢复入口。
4. terminalReady/Output 回调位于工作线程，界面须按上述约定绑定和派发；终端网络读完后，视图应继续排空待绘制队列。窗口产品入口的替换未包含在本阶段。
5. 退出码仅代表 menu.sh 进程返回值。菜单内部动作和后续下载仍由上游原脚本决定；状态协议不提供同等远端权限进程的防篡改保证。

原未提交工作区和已有修改已保留；无 stash/reset/clean、提交、推送或真实设备操作。
