# iStoreOS 插件安装助手 V1.1.0

准备日期：2026-10-29（Asia/Taipei）。本地正式版本和发布包已准备，尚未提交、创建 Tag 或发布 GitHub Release。

## 主要变化

- 首页支持选择或拖入 `.run`、`.ipk`、`.apk` 本地安装包。
- 自动识别 OPKG / APK；IPK 只允许 OPKG，APK 只允许 apk-tools 设备。Android APK 不受支持。
- 原生包读取包内名称、完整版本、架构和安装大小，严格检查包管理器 / 架构；IPK `all`、APK `noarch` 分别按无关架构处理。
- 复用软件源检测、真实 package update、空间检查、SFTP、两端 SHA256、安装前后包快照和独立结果验证；原生包必须通过远端 SHA256，并精确核对目标完整版本。
- `.run` 保持 SDK / 架构规则、Makeself 校验及作者原始安装器执行链。
- 安装日志的共用描述统一为“安装包 / 安装器”；格式专属校验和真实执行命令仍准确显示。
- “插件维护”打开原项目菜单终端，支持输入、复制粘贴、滚动、UTF-8、窗口尺寸与 PTY 同步，以及退出状态和最终输出排空。
- 连接后后台优先检测设备 GitHub Raw 直连；直连失败时检查 Windows localhost HTTP 代理。点击维护入口时再次复核，API 仅作诊断。
- 电脑代理使用专用 SSH #2 承载 N1 回环端口 17890 转发；代理环境仅供本次 menu.sh 及子进程使用。关闭时释放 SSH #2 并检查端口，保留首页 SSH #1；直连不创建隧道。
- 首页 SSH 按钮支持“连接 / 断开”，安装或维护期间禁止断开，断开清除当前设备与维护状态。
- 删除旧七插件按钮页面、专属版本扫描、单脚本执行与软件源子窗口，保留当前菜单复用能力。
- 成功安装后保留选中的可用官方源，失败继续原有恢复流程；未知安装状态不重复派发或提前清理。

## 保留的边界

- 原生包的依赖、ABI、签名和实际可用空间由设备包管理器进一步校验；不自动添加 `--force-*` 或 `--allow-untrusted`。
- 菜单从 upstream main 下载原始 menu.sh / LICENSE；main 可变化，SHA256 确认本次字节传输一致，不代表固定上游版本或来源可信。
- 未知状态保留远端任务；关闭终端或隧道不证明所有远端派生操作已停止。首页 SSH 已断时，端口释放可能只能记录为未知。
- 不自动启用插件，不修改永久代理 / 软件源以实现电脑代理；首次安装需要时的官方源切换沿用既有策略。
