# V0.3.2.7 圆角按钮黑边修正

日期：2026-10-13。基线：V0.3.2.6。用户授权按已完成的绘制诊断修复。

**Release x64：0 warning / 0 error；261 passed / 0 failed。**

## 修正与范围

`RoundedButton` 继承的 `ControlStyles.Opaque = true` 跳过背景绘制，而圆角前景无法覆盖控件区域中的全部边缘像素。预填缓冲区的检查能稳定显示残留，与启动或安装结束后出现黑边、鼠标移入后消失的现象一致。

本轮唯一功能改动是在共用圆角按钮构造函数中添加 `SetStyle(ControlStyles.Opaque, false)`，恢复透明父背景绘制。`RoundedIconButton` 和高级导航 `SegmentButton` 继承修正。不更改绘制路径、颜色、圆角、布局、启用条件、事件或键盘焦点提示，不增加边框、不强制定时刷新。普通原生确认按钮保持原实现。

其他产品文件变更仅为版本信息和 MainForm 启动日志的版本字符串。安装、SSH、软件源、Retry、恢复、验证、Package Diff、日志写入 / 缓冲 / 保存 / 复制逻辑保持。

## 验证

原有 259 项测试全部保留并通过，新增两项有效回归：

- 预填非背景色缓冲区，检查主按钮、次按钮、普通圆角按钮、图标和分段导航在初始、悬停、按下及禁用状态完整覆盖区域内像素；覆盖 100% / 125% / 150% / 200% 几何缩放。
- 在真实 MainForm 上循环八次启用、聚焦、禁用、局部失效及鼠标移入 / 移出，检查安装按钮边缘无残留、位置不跳动、窗口仍为 760×500；不触发 Click 或安装。

独立绘制审计清点 44 个控件、92 个绘制案例。15 个共用圆角按钮实例全部取消 Opaque；85 个圆角按钮 / 导航状态在修正前均有未绘制像素，修正后的完整绘制均为 **0 未绘制像素、0 黑色边缘像素**。只绘制前景到黑底的对照仍刻意保留，用于证明背景覆盖的必要性，不代表实际完整绘制结果。内部正常焦点提示保留。

UI Smoke 使用 fixture，覆盖主窗口未连接 / 未选择、已连接 / 已兼容，以及高级窗口各页、长行 / 长日志、Resize / Maximize 和 125% 缩放。肉眼检查主窗口两个状态、完整日志页的导航与底部按钮，以及禁用后获得焦点的绘制对照：边缘连续，原色与布局保持。此检查没有改变系统 DPI，Windows 7 和原生多屏 DPI 尚未重新实机验收。

源文件 SHA256 与修改前基线逐项核对，全部非授权文件保持；主窗口布局、高级信息结构和 Palette 文件未变。核对报告记录允许变更清单及原有测试完整性。

没有连接真实路由器或执行真实 `.run`。真实 PassWall 仅用于既有只读元数据 / SHA256 检查。
