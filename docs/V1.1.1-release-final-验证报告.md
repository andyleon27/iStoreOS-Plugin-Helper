## 验收边界

`.run` / IPK、插件维护终端及电脑代理已完成 N1 实机验收；本地 APK 已完成离线测试和真实样本解析，尚未实机安装验收。RC1 真实用户测试的总体通过反馈不替代未提供的逐设备验收记录。Windows 7 SP1 x64 尚未专项实机验收。

无 SFTP 兼容只覆盖本地安装链；维护菜单准备继续使用 SFTP。定制服务器仅允许当前库不支持的算法时仍可能没有交集；网络、认证、Host Key 异常或未知安装状态仍按原安全边界停止，不切换弱算法或猜测成功。

V1.1.0 原始 ZIP 和 SHA256SUMS 保持不变，不重新构建或打包旧版本，不修改旧 Release。
