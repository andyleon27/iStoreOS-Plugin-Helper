# iStoreOS 插件安装助手 V1.0 RC1

版本：**1.0.0-rc1**。这是发布候选版本，用于最终验收与公开发布准备。

通过 Windows 图形界面连接 iStoreOS，安装本地 Are-u-ok `.run`，自动完成环境与兼容性检测、动态软件源探测、上传校验、安装验证、日志记录和清理。对明确的官方源错误有限重试，并尝试恢复临时修改的官方源。

用户已实测 PassWall 26.9.16、OpenWrt-momo 1.2.1；两者通过同一套通用安装链路完成。RC 本轮不重复安装，不自动开启代理插件或修改代理配置。

## 系统要求

Windows 10 / 11 x64 + .NET Framework 4.8。兼容目标为 Windows 7 SP1 x64 + .NET Framework 4.8，尚待专项实机验收。路由器使用 iStoreOS，安装包须匹配设备 SDK 和架构。

## 使用

从插件作者官方发布渠道下载适配的 `.run`。解压 ZIP 并运行 EXE，连接路由器，拖入文件，确认兼容后点击“安装插件”，等待结果。保留同目录 DLL、config 与许可证文件。

SSH 密码不会保存到磁盘。安装完成后自行在 LuCI 配置和启用插件。如遇异常，请打开“高级信息 → 完整日志”，保存日志用于排查。

发布包：`iStoreOS.PluginHelper-v1.0.0-rc1-win-x64.zip`。校验文件：`SHA256SUMS.txt`。此阶段未上传 GitHub，也未创建正式 V1.0 Tag。
