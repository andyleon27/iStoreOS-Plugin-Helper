## 兼容性与安装安全

- ARM64 架构按既有语义规则匹配，保留原始架构值和 SDK 严格匹配；A53 / A72 继续区分，`aarch64_generic` 保持安全规则。没有 ARM、N1 或 OPKG 专用安装分支。
- 使用通用 OpenWrt / BusyBox 能力适配，移除安装临时目录和包管理器锁检查对 `stat` 的运行时依赖；保留 GUID 独占目录、0700 权限、symlink 检查、包管理器占用检查和受限清理。
- Runner 不再依赖外部 `nohup`，使用 shell HUP trap，并保持 `launch.once`、标准流脱离、原退出码和原子 `exit.code`。
- Runner / Poll 不再使用 `base64` / `dd` 传输日志或结束状态。受信任 SFTP 直接读取原始 byte[]，stdout / stderr 独立 byte offset，每路每次最多 65536 bytes，严格解析 exit，结束后排空尾部日志。
- Monitor 生命周期复用一条受 Host Key 验证的 SFTP 连接；断线通过原工厂有限重连同一 RemoteTempSession / offset，不重新启动安装器。上传 SFTP 保持独立生命周期。
- QuickStart 动态候选为唯一镜像来源，无硬编码镜像数据库或固定品牌排名。健康当前源保持 Canary + 真实 update；异常时按有限 Fast Canary、实时延迟、Good Enough / FULL 验证选择镜像；快速超时保留正常超时 fallback。
- 保留真实 `apk update` / `opkg update` 安装前 Gate；临时切换须通过实际 identity 与完整 distfeeds 验证。辅助 / 自定义源不作为官方镜像轮换依据。
- 临时换源安装结束后恢复安装前原始官方 distfeeds，并核对原文 / hash；状态未知不重复启动或提前清理，恢复失败保留备份并提示。
- 上传大小、SHA256、Makeself、空间与包管理器检查、有限安装重试安全边界保持。
- Before / After Package Snapshot 完整保存在内存，Package Diff 与主 package 独立验证保持；日志仅输出快照数量、完整变化项和 Timing Summary。

本次通过通用 OpenWrt / BusyBox / 架构语义适配，改善 ARM64 / OPKG 环境兼容性；已在 N1 aarch64_cortex-a53 上完成真实安装验证。这不是对所有 ARM 设备、所有固件分支或所有第三方安装包的兼容保证。
