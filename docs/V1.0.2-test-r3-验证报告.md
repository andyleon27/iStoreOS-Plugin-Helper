## 流程与安全 Gate

健康当前源：读取实际官方 distfeeds → readiness / 包管理器占用检查 → 官方 Canary → 真实 apk/opkg update → 原安装服务。update 成功时不读取 QuickStart candidate list，也不对其他镜像发出 HTTP 请求。

Canary 只从官方 feed 中选择，优先有效的 base/Packages.gz 或 base/packages.adb；否则选择第一个有效官方 feed。没有有效官方 feed 时无法证明可达。compat / custom / additional 不充当 Canary。Canary 成功仅表示可达，未完整验证时按完整 feed 总数显示 PARTIAL；Ready 仍必须通过真实 update。

当前 Canary 失败不检查其剩余 feed。候选由 QuickStart 动态读取，HTTPS 优先，同协议保持原顺序；失败 Canary 立即淘汰。成功后复用该结果，串行检查剩余官方 feed，任一失败即转下一个；首个 FULL 立即暂停搜索并使用。

本轮缓存 key 为规范化 source URL + 规范化 index URL + parse error。成功和失败均缓存；新一轮重新建立缓存。URL 规范化处理 scheme / host / 默认端口和尾斜杠，保留路径大小写。唯一镜像及相同完整 feed 集合不重复尝试；当前源在候选列表再次出现也跳过。

切换前保留原配置竞态检查和原文备份校验；切换后核对实际 identity 与完整 distfeeds。完全匹配的已验证 FULL URL 集合不再发 HTTP 请求，直接运行真实 update。只有明确官方仓库错误才继续下一个未尝试的唯一候选；辅助源、非源错误、冲突等按原安装失败策略停止。安装器明确官方源错误的有限续装仍复用同一个惰性候选序列。

安装快速路径记录辅助 / 自定义源配置，并将它们交由真实 update 处理；逐 URL 完整 HTTP 诊断保留在高级软件环境检测中。它们不决定官方源轮换。

SDK / Architecture、实际换源验证、真实 update、空间与锁、上传完整性、SHA256、Makeself、主 package 验证、原源恢复及 Package Diff 保持原 Gate。没有并行 Probe，没有 ARM / OPKG / N1 专用源选择分支，没有硬编码镜像数据库。
