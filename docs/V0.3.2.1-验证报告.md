## 1. 参考图与主窗口

开发前查看了用户提供的 `docs\ui\v0.3.2.1-compact-reference.png`，采用其浅灰背景、白色内容区、蓝色主按钮、紧凑表单与次要高级入口的层级。参考图不进入程序资源，也不作为背景；截图中的设备、插件和软件源示例数据不进入程序常量。

- 100% DPI 的 **ClientSize：760×500**。
- `FixedSingle`，`MaximizeBox=false`，保留最小化，延续 `AutoScaleMode.Dpi` 与现有系统 DPI manifest。
- 外边距左右 20px；两块白色内容区之间 14px；输入组之间 10px。
- 顶部布局 58px；连接内容区 108px；插件区 160px。
- 拖拽区实际高度 72px；主按钮 **200×40px**，水平居中，启用蓝色 / 禁用灰色。
- 状态区 **48px**，使用两行 Label，不使用多行 TextBox 或滚动条。
- 只保留连接、插件两个主要内容区。主窗口没有完整日志、保存按钮、技术面板或文件路径。
- 连接、选择文件、安装中、成功、失败和打开高级信息均不主动调整主窗口尺寸。

连接行显示实际检测的版本、SDK、架构和包管理器。选择文件后只显示实际插件名 / 版本与兼容性摘要；文件名、路径、大小和完整元数据放到高级窗口。拖放保留，拖拽区点击也可选择文件。密码显隐和连接后清空行为保留。

## 2. 独立 AdvancedInfoForm

**ClientSize：800×600**，可缩放、可最大化，最小外部尺寸 640×480。由主窗口拥有的非模态窗口，主窗口仍可操作。

“高级信息 ›”打开或激活同一个窗口，不在 MainForm 内展开区域。关闭高级窗口只隐藏它，不销毁数据、不取消检测或安装；再次打开保留日志和所选页面。主窗口释放时一并释放高级窗口。

| 页面 | 信息与操作 |
|---|---|
| 系统信息 | 系统版本、SDK、架构、包管理器、QuickStart、地址、连接状态、SSH 指纹 |
| 软件源 | 当前源、官方 feed、compat / custom、Package Update、逐项 URL / HTTP / exit / 错误、stdout / stderr、原诊断入口 |
| 安装过程 | 完整文件名 / 路径 / 大小 / 元数据 / 兼容性、SHA256、Makeself、安装器结束证据、主 package 独立验证、恢复 / 清理 / 提示及各次 attempt |
| Package Diff | 原业务结果的新增、版本变化、删除及各次 attempt 记录 |
| 完整日志 | 原有完整实时日志显示，允许滚动、选择和复制 |

底部只有一个可见“保存日志”，在五个页面均可使用，沿用完整会话快照及 UTF-8 BOM 写入。视图关闭期间三个日志流仍写入同一个显示控件与完整内存记录；界面显示缓冲裁剪不影响保存全文。失败时主窗口显示“查看详细信息”，直接打开完整日志页。

原 scoped 导出处理器和两个隐藏兼容按钮留在高级窗口，便于原日志回归继续验证；没有第二个可见保存入口。取消准备仍调用原处理器，dispatch 后继续禁止取消和关闭主窗口。关闭高级视图不影响这些限制。
