## Release Code Audit

全项目文本扫描结合关键流程手审：SSH / SFTP 身份验证、凭据生命周期、日志脱敏、动态软件源 / 原源恢复、安装命令、重试与故障分类、Package Diff / 独立验证、发布脚本及配置。所有 26 个服务文件与修改前 SHA256 保持一致，没有核心逻辑重构。

发现并修正：

1. MainForm 的正常关闭会释放 SSH 会话，但直接 `Dispose()` 未走同样清理。现在 Dispose 同样取消关闭令牌、清空密码框并调用已有 `SshService.Dispose()`，释放认证工厂与脱敏闭包引用。没有引入复杂内存清零。
2. 连接界面把所有失败覆盖成通用 IP / 用户名 / 密码提示。现在保留已有 `ConnectionResult.UserMessage`，Host Key 变化会明确显示已拒绝连接和核对设备的下一步。
3. 旧便携脚本会携带 README 和验证报告，且版本命名属于开发阶段。本轮改为从实际引用生成运行时文件白名单，最终 ZIP 平铺 EXE / DLL / config，仅附必要的第三方许可通知。
4. 三份历史验证文档含个人下载目录。原文已保留在忽略的本地证据目录中，公开文档只把个人路径替换成 `<本机插件目录>`，验收数据和结果未删改。
5. 补齐 .gitignore 中常见用户状态、PDB、临时文件、dump 等规则。已有 artifacts、.tools、packages、运行日志和 `.run` 排除规则保持。

扫描未发现：公开产品源码中的 Console / Debug 输出、开发 MessageBox、运行相关 TODO / FIXME、开发机绝对路径依赖、真实密码 / 私钥 / API Key / Token 常量。所有公开候选文本未发现用户目录或用户名路径。测试中的合成 secret 仅为 fixture，不是用户凭据。原始运行日志、开发截图、工具、bin / obj、NuGet 包和用户安装包不进入公开源码候选或用户 ZIP。

### 硬编码与通用性

- `192.168.100.1` 和 `root` 在产品中仅为可修改的 UI 默认值，没有针对该地址 / 用户名的安装分支。
- `25.12.5` / CERNET 等示例不作为产品业务条件；SDK / Architecture / 包管理器来自当前设备检测。
- 插件解析器中的名称列表属于已知文件名规则。PassWall / OpenClash 的主 package 对应关系属于明确的验证规则；其他插件采用通用 package diff / 唯一候选 / 独立查询，不要求插件必须叫 PassWall。
- 新增 Momo 回归使用 Fake 安装 session：`luci-app-momo 1.2.1-r1` 独立验证成功，`sing-box 1.14.1-r1 → 1.13.16-r1` 如实记录为 Updated，结果仍为 SuccessVerified，没有额外默认警报。

### SSH、密码及日志

- 首次 Host Key TOFU 仅限当前程序运行，SHA256 指纹显示到高级日志。指纹变化拒绝连接，重连 / SFTP 必须匹配原受信任记录，没有无条件信任或系统 known_hosts 写入。
- 密码默认隐藏，临时显隐不记录文本；开始连接后清空框并恢复隐藏。认证工厂只在当前会话内存保留，以支持既有断线恢复；暂时网络中断不主动丢弃恢复需要的凭据，关闭 / Dispose 后释放引用。
- SSH 输出和异常消息经过已有脱敏，日志不会序列化 Credential / SecureString / 认证对象。配置只包含 .NET Framework 启动与程序集绑定，无 SSH 私密数据。
- 日志文件仅由用户主动保存；地址、URL、package、SHA256、目录和退出码为允许的诊断数据。原始真实日志不自动公开。

### 软件源与安装边界

- 候选来自目标设备当前 QuickStart，使用实际 ROM 模板构建与探测，不维护长期镜像数据库。
- 直接官方配置写入与恢复目标仅为 APK `/etc/apk/repositories.d/distfeeds.list` 或 OPKG `/etc/opkg/distfeeds.conf`。compat / custom 配置由工具只读；QuickStart POST 沿用设备既有接口。
- 首次切换前保存原始完整内容并复核备份；收尾在安装器确认结束后 best effort 恢复原文与 SHA256。未切源时不额外写官方配置。待确认安装器 / 恢复失败时保留状态与备份，不启动第二个安装器。
- 有限重试只响应可归属于官方源的明确下载错误。兼容、完整性、脚本、冲突、kernel ABI 等失败不冒充镜像失败。
- 不启停 PassWall / PassWall2 / OpenClash / Momo，不改 UCI / 代理模式，不自动卸载或回滚依赖。执行内容仍由原作者 `.run` 决定。
- Package Diff 是高级诊断数据；正常 Added / Updated / 依赖降级不会单独将已验证成功的安装改判失败。

主要错误提示已审计：网络、时间、空间、包管理器占用、软件源、安装包完整性、身份变化、独立验证和工具异常均提供下一步。技术详情保留在高级日志。
