## 3. 准备、执行、结果和清理

复用 Phase 2A：每次任务解析一次 main 完整 commit SHA；原始脚本与 LICENSE 从同一个 SHA 下载；生成来源 NOTICE；Windows 计算 SHA256；使用受信任 SFTP 上传至 `/tmp/istoreos-plugin-helper/maintenance-<任务ID>/`；远端三个文件 hash 全部核对后，直接通过 SSH command 调用 `sh '<本任务脚本路径>' '<固定映射参数>'`。未将脚本安装到 /usr/bin、/root 或 /etc。

`PrepareScriptAsync` 仍可单独做准备预览并清理；这种已经清理的 preview plan 不能单独执行。真正执行只在 `RunScriptAsync` 的同一校验与工作目录生命周期中发生，不另建旁路框架。

结果只按 SSH command 退出码确定，不分析脚本文字：

- 0：操作完成。
- 非 0：操作失败，显示退出码并保留输出。
- 连接异常或没有退出码：**连接中断，无法确认操作最终状态。**

退出码结果与清理警告分别记录；例如 exit 0 但远端无法清理时，保留完成结果并明确显示残留目录警告。SSH 断开时不会声称远端文件已删除；Windows 文件仍尝试清理。

继续复用原远端精确文件清理、归属检查、独立 20 秒 cleanup token 和本地空目录删除。单任务 SemaphoreSlim 从准备一直持有至执行与清理结束，SshService 既有忙碌门禁同时防止读写工作重叠。

## 4. 实时输出与界面行为

分别异步读取 OutputStream / ExtendedOutputStream，使用独立 UTF-8 decoder 按块转发，支持没有换行的进度或提示以及跨块中文。不会等执行完才读取 Result / Error。两个流都带 `[Third-party Script]`；工具诊断带 `[Plugin Helper]`，stderr 属性在日志数据中单独保留。保留文本换行和内容，继续使用现有敏感信息遮盖；两条独立流的全局交错顺序取决于到达时序。

Progress 和 await continuation 显式绑定 WinForms 同步上下文。新增无 ambient context 的 UI 用例启用非法跨线程检查；解决了该宿主条件下日志回调进入线程池的问题。任务 ID 和扫描代数拒绝旧回调。UI 日志保留跨刷新会话，超过约 1 MiB 时截去最旧部分，避免无界增长。

按钮策略：未安装显示安装；已安装显示更新 / 卸载；版本一致或本地较新时更新禁用；版本状态待确认仍允许更新；在线服务不可用时全部禁用。部分组件按已有安装处理，无法确认安装状态时不开放操作。

任务期间禁用全部行操作和重新检测。下载、上传、hash 等准备阶段可“取消准备”，随后仍清理。进入 Executing 后不传 UI cancellation token 给 shell，SSH command 无本工具额外运行超时，取消按钮禁用；正常关闭窗口也被阻止，提示等待自然结束，不 Kill / CancelAsync / 断开 SSH 来宣称取消。

服务完成清理后，窗口自动复用原只读检测，先显示本地状态，再渐进读取远端版本。操作结果和错误输出保留，无需关闭窗口重开；安装后显示更新 / 卸载，卸载后显示安装。准备时主动关闭窗口会先取消和清理，然后关闭。

SSH.NET 流转发依据本项目使用版本的 [SshCommand](https://github.com/sshnet/SSH.NET/blob/2026.0.0/src/Renci.SshNet/SshCommand.cs) 和 [PipeStream](https://github.com/sshnet/SSH.NET/blob/2026.0.0/src/Renci.SshNet/Common/PipeStream.cs) 行为实现；等待命令与两个流全部结束，保留关闭后仍可读取的缓冲输出。未分析第三方插件脚本内部逻辑。
